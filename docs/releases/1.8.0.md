# Electricity Pro v1.8.0 beta and upgrade notes

**Current beta: [v1.8.0b2](https://github.com/guslund-jpg/electricity-pro/releases/tag/v1.8.0b2),
the second GitHub pre-release toward v1.8.0.**
**v1.7.2 remains the latest stable release.**
Use a separate test installation for beta testing.

Requires **Home Assistant Core 2026.9.0 or newer**. The current Core baselines
use Python 3.14; the minimum remains unchanged.

## Changes since v1.8.0b1

- Use four views in Swedish and English Standard and Enhanced: **Overview**,
  **Prices**, **Energy and costs**, and **Electrical Details**. Overview focuses
  on current power, Effective Price, cost rate, advice and cheapest 1/2/3-hour
  windows. Prices retains those windows; daily/monthly import and separate
  export statistics move to Energy and costs. (#436, #439)
- Add native six-hour power history and a collapsible spot-price forecast table
  to Standard. The table uses HA's local time zone and retains zero, negative
  and missing prices without Mushroom, ApexCharts or helpers. (#439)
- Label Enhanced's 24-hour power graph as five-minute averages, with the latest
  Current Power sensor reading above both power graphs. Hide the monthly
  peak-hour heading when its optional values are unavailable. (#434, #439)
- Clarify the separate VAT coverage of monthly spot-cost rows without changing
  calculations or totals. (#437)
- Add optional **Enhanced Clean** in Swedish and English. It keeps Enhanced's
  values, charts and visibility with compact day/month card groups and fewer
  explanatory text cards. Estimate/partial labels and More info remain available.
  Standard and the existing Enhanced remain available. (#441)

Since b1, the integration files change only in the manifest version. The dashboard
updates require copying YAML separately; upgrading the integration alone keeps
existing dashboards as they are.

## Changes since v1.7.2

- Show monthly variable cost components, accrued fixed supplier/grid fees,
  earlier unsplit costs, VAT where its basis is known and display rounding.
  Retain component statistics in Recorder and a local monthly archive. (#165)
- Add the stacked monthly variable-cost chart to Enhanced in both languages,
  with month/component tooltips, coverage notes and a legend that hides entries
  without recorded amounts. Known zero remains visible. (#410–#413, #421)
- Organize English/Swedish Standard and Enhanced into four views, add optional
  Enhanced Clean and retain phase measurements first and power history last in
  Electrical Details. Document independent fixed gauge scales.
  (#403, #420, #436, #439, #441)
- Add optional signed fixed export pricing, meter-scoped price periods,
  persistent interval booking and separate daily/monthly compensation estimate
  sensors. Standard, Enhanced and Enhanced Clean show the estimates with partial
  coverage labels in both languages. (#241, #423, #424, #426–#428, #430, #441)
- Complete the source/result separation and observation-history refactors while
  preserving settings, existing entity identities, Decimal semantics and saved
  history. (#288)
- Wait for configured Nord Pool setup at startup and recover the Next
  inexpensive 1h window when a comparable forecast first arrives later. (#429)

## Upgrade and dashboards

Before testing, make a recovery backup including HA configuration, Electricity
Pro settings/statistics and the Recorder database. Keep the existing integration
entry. Select **v1.8.0b2** in Marketplace/HACS and restart Home Assistant;
check live readings, forecasts, existing IDs/settings and accumulated totals.
Do not delete/recreate the entry or clear statistics to perform an upgrade.
Rollback uses the matching recovery backup; downgrading code alone has not been
validated as a saved-data rollback.

Dashboard examples are copied separately. Replace an existing dashboard's raw
YAML with the example for its language and variant, carrying over custom entity
IDs, scales and other local changes. An integration upgrade does not rewrite
dashboards. **Standard uses only built-in cards**; Enhanced and Enhanced Clean
require **Mushroom and ApexCharts Card**. Choose one variant in either language,
or keep separate dashboards to compare them:

| Variant | English | Swedish |
| --- | --- | --- |
| Standard | [YAML](../../examples/dashboards/electricity-pro.yaml) | [YAML](../../examples/dashboards/electricity-pro-sv.yaml) |
| Enhanced | [YAML](../../examples/dashboards/electricity-pro-enhanced.yaml) | [YAML](../../examples/dashboards/electricity-pro-enhanced-sv.yaml) |
| Enhanced Clean | [YAML](../../examples/dashboards/electricity-pro-enhanced-clean.yaml) | [YAML](../../examples/dashboards/electricity-pro-enhanced-clean-sv.yaml) |

Carry over custom entity IDs and scales. Old `trends` links move to `prices` or
`energy`. See the [dashboard guide](../../examples/dashboards/README.md).

Cost-component history starts when component data was recorded. Older costs
remain explicitly unsplit, and earlier monthly chart data is not reconstructed
from Recorder. Partial months and missing intervals retain coverage
notes. The chart covers variable import costs; fixed fees and separate export
compensation are not added to its stacks. Estimates exclude unconfigured fees.

## Fixed export compensation is experimental

Select a compatible directional lifetime export register and separately declare
its fixed price, currency, VAT and included compensation components. Import
prices, signed net power, production and battery readings are not substitutes.
See [configuration and limits](../guides/production-export.md#fixed-export-price-beta).

The amount is signed: 2 kWh at −0.20 SEK/kWh gives **−0.40 SEK**, a cost for
export. Known zero stays available; missing data does not become zero. Import
costs remain separate. An interval needs one price covering its full duration;
an interval spanning a price change remains unpriced. Price changes preserve
earlier bookings and do not retrospectively price earlier gaps.

Coverage always remains partial, including when all observed export was priced.
These estimates are not a complete bill or verified supplier settlement.
Mixed currency/VAT/component declarations can withhold a period's amount.
Already booked values can remain visible during source gaps or with pricing
disabled, accompanied by status attributes/notes.

A new local day can temporarily show unavailable until its first priced interval
is checkpointed. A known-zero run observed a **60.6-second** gap at midnight;
this is an observation, not an availability bound. Publication follows saved
checkpoints. Abrupt power loss can lose updates since the last successful write,
normally up to one minute with functioning storage.

Real nonzero export, signed live compensation, nonzero partial pricing and a live
month boundary remain unverified. Physical solar/battery evidence and agreement
with actual compensation await an equipped beta tester in
[#335](https://github.com/guslund-jpg/electricity-pro/issues/335) and
[#241](https://github.com/guslund-jpg/electricity-pro/issues/241).

## Outside this beta

- Demand-charge invoices, hourly grid-import collection and tariff estimates
  from #414–#416 were reverted by #417. That part of #165 remains paused.
- Provider-independent monthly peak-hour statistics (#312) are parked and
  excluded from v1.8.0. Existing configured provider peak-hour sensors retain
  their meaning and identities.
- Supplier/market-linked export prices, site-balance calculations, battery
  control and flexible-load recommendations remain future work.
