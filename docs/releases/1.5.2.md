# Electricity Pro v1.5.2 — Startup Timezone Fix

Released 29 October 2026. See the
[published release](https://github.com/guslund-jpg/electricity-pro/releases/tag/v1.5.2).

This focused maintenance release is based on v1.5.1, not the unreleased
production/export work on main. It reuses Home Assistant's already-loaded timezone
during setup and reload, avoiding potential timezone-database disk reads on
Home Assistant's event loop. Local day/month boundaries and daylight-saving
behaviour retain their existing meaning.

## Upgrade

1. Take a Home Assistant backup.
2. Install v1.5.2 and restart Home Assistant.
3. Verify that Electricity Pro loads, readings remain available and there are
   no Electricity Pro timezone-related blocking-call warnings.

No configuration migration, meter reset, historical recalculation or dashboard
change is required from v1.5.1. For earlier releases, also read the
[v1.5.1 upgrade notes](1.5.1.md).

The maintenance release excludes unreleased v1.6 production/export, household
demand, compatibility diagnostics, VAT suggestions and Tibber addition estimates.
Returning from manually installed development code to v1.5.2 removes access to
those development-only features; retain a backup before switching.

## Release boundaries and validation

The release tag and `release/1.5` maintenance line are separate from main.
Main's manifest may still show 1.5.1 while development continues; the manifest
alone does not identify a manually copied development snapshot. Record the Git
commit when testing main. Documentation updates do not change that version.

The maintenance release passed 570 tests, including setup/reload timezone
regressions and existing local-day/tariff tests. Later main-only CI and feature
changes are not part of this release.

This addresses feedback from the
[HACS submission](https://github.com/hacs/default/pull/10261), but publishing a
release or passing validation does not itself constitute catalogue acceptance.
