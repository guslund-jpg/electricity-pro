# ADR-0014 — manual continuity and tariff verification

**The configured development instance passed the functional checks for
ADR-0014.** The report summarizes the observed outcomes for build `31d7fa6`
on Home Assistant Core 2026.11.0. [ADR-0014](../adr/0014-source-readings-and-integration-results.md)

## Builds and evidence

- The installed Marketplace baseline matched the tracked v1.7.2 component
  files at `5df07c5`.
- The development installation matched the 47 tracked component files at
  `31d7fa6`, the merged tree for the three implementation stages.
- The two pinned automated suites on Core 2026.9.0 and 2026.10.4, strict typing
  and the six PR checks provide the automated evidence. [Implementation PR #393](https://github.com/guslund-jpg/electricity-pro/pull/393)

The maintainer retains the capture files, registry comparisons and log evidence
privately. The public record summarizes test outcomes and uses commit IDs to
identify the builds.

## Observed outcomes

| Check | Result | What was verified |
| --- | --- | --- |
| Upgrade, reload and restart | PASS | Configuration validation succeeded before the upgrade restart. The integration resumed live readings and forecasts after upgrade, reload and a subsequent restart. |
| Entity and settings continuity | PASS | The entity and device registry comparisons matched the saved identities, names and associations. Saved configuration and options matched the baseline. The public state comparisons covered the configured entities and their existing availability. |
| Saved history | PASS | The statistics schema matched the baseline. The completed timing result survived the lifecycle transitions and the stored result for the completed day matched its published state and attributes. |
| Local-day rollover | PASS | Daily energy, cost estimates and peak period reflected the new day. The monthly energy increment matched the raw import register increment exactly. Monthly tracking and supplier cost continued. |
| Tariff selection | PASS | The grid charge inferred from the Effective Price, supplier price and configured tax matched the selected low and high tariffs under the captured Workday states. |
| Forecast and live values | PASS | The forecast expired the prior delivery day and retained matching rows for the new day. Current market intervals covered the capture times, and the cost rate matched power × Effective Price. |

## Scope of acceptance

The snapshots establish the observed overnight outcomes. The automated boundary
and DST fixtures cover transition timing. The configuration-check output and
maintainer lifecycle reports support the upgrade/reload/restart results. The
overnight functional verdict uses the two state exports and the saved-file
comparisons. Performance measurements and log details are retained in the
private evidence for review.

The manual evidence applies to the configured instance and its source setup.
Unavailable features contribute availability evidence. The later runtime
changes in #395–#399 require a separate manual run. Real solar and battery
validation has its own scope. [Issue #288](https://github.com/guslund-jpg/electricity-pro/issues/288), [Hardware validation #335](https://github.com/guslund-jpg/electricity-pro/issues/335)
