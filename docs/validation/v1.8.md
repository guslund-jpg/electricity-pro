## Beta observation checklist

These are follow-up checks, not newly recorded passes. Observe normal use over
several days and retain the exact tag, Core version, time zone, capture times,
source readings, relevant attributes and redacted logs for any discrepancy.

- [ ] Import-energy increments agree with the configured meter; costs accumulate
  without unexplained jumps or duplicate booking.
- [ ] Nord Pool forecasts and inexpensive windows continue updating; new
  integration/template warnings or errors are investigated.
- [ ] Monthly estimate components plus any rounding line match the gross total;
  itemized VAT is already included. Enhanced's variable-cost tooltip components
  plus its rounding line match the archive table. Existing dashboards need
  updated YAML with local customizations retained.
- [ ] Daily values reset at local midnight, monthly values continue and Recorder
  history remains intact. The previously observed **60.6-second** daily export
  availability gap remains documented, not an availability guarantee.
