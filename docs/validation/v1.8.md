**Status: v1.8.0b1 preparation; not published.** Scope and user-facing limits are
in the [beta notes](../releases/1.8.0.md). #241 and #335 remain open; #312 is
parked outside v1.8.0. The demand-charge work reverted in #417 remains paused.

## Builds and compatibility

- Preparation base: `e847025` ([#430](https://github.com/guslund-jpg/electricity-pro/pull/430)).
- Source integration files match the runtime build `eef3a65` (#429); #430 added
  dashboard examples, documentation and tests. The beta preparation changes
  only the integration's manifest version, to **1.8.0b1**, plus release documents.
- A 21 November read-only comparison confirmed all **55** installed integration
  files matched `e847025` before the beta version change. The configured test
  instance runs **Core 2026.11.2**. It has not been upgraded to the versioned beta.
- Retain Core **2026.9.0** and Python 3.14 as the minimum. The current stable
  Core/harness review is recorded in the [development guide](../development/contributing.md#v180-beta-review--21-november-2026).
  No additional version adapter removal is justified; saved-data migrations and
  compatibility with existing settings remain required.

Exact candidate commits, archive checksums and GitHub checks belong in the
release-preparation PR. A manifest version alone is not a published or manually
verified package.

suites with the following actual environments. The only integration-file change
from the reviewed source base is the manifest version.

Repository validation, Ruff lint/format and mypy also passed. README logo and
screenshot references/assets were compared with the preparation base and retained.

Automated coverage includes price boundaries, duplicates, replay prevention,
source gaps, negative/zero amounts, persistence, calendar boundaries, clock
changes and actual Recorder statistics/restart restoration. Dashboard tests
render HA Jinja and evaluate the native visibility conditions for missing,
signed, zero, partially covered and retained booked values. These checks do not
constitute real export or supplier-settlement evidence.

Full integration-suite coverage on Core 2026.11.2 remains a gap: the latest
available harness targets 2026.10.4. The stable-HA configuration workflow and
the following configured-instance tests are separate evidence.
