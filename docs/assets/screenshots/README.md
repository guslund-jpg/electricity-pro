# Dashboard screenshots

Real installation screenshots supplied by the project maintainer for the README
on 31 October 2026. The PNGs are copied without altering readings or labels.
They show a user-configured Enhanced dashboard, not a promise of the exact layout
in the current example YAML or evidence of solar/battery hardware validation.

- `enhanced-overview.png`: live gauges and daily/monthly cards.
- `enhanced-trends.png`: recorded power and market/supplier/effective prices.
- `enhanced-forecast.png`: market forecast and cheapest 1h/2h/3h windows.

The overview retains older supplier-cost labels. The trends chart's “Household
power” uses Current Power, not the optional measured household-demand input.
Forecast window averages and the market-price graph have different price scopes.
Keep the explanatory captions in the root README when reusing these images.

No names, addresses, account identifiers or credentials were visible in the
selected images. Household readings, dates and Swedish formatting are visible.
Review replacements for private information before publishing them.
